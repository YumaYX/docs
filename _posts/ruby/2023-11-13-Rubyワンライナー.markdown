# Rubyのワンライナー

## 置換

```sh
$ cat a
2
$ ruby -nle 'puts $_.gsub(/2/,"two")' a
two
$ 
```

## 計算

```sh
seq 10 | ruby -ne 'sum||=0;sum+=$_.to_i;END{puts sum}'
## => 55
```

## 抽出

```sh
ruby -nle 'puts $_ if $_ =~ /^abc/' file
```

### オプション

| Option | Desc. |
| --- | --- |
| -e command | 実行するRubyコード |
| -l | 各行を$_に代入し末尾をchomp |
| -n | 1行ずつ処理(-eと併用) |
| -r lib | requireするライブラリ |

※ `$_` はオプションではなく、1行分の文字列が入る組み込み変数

#### アルファベットを利用する場合

```sh
ruby -e "puts ('a'..'z').to_a" | while read line; do echo ${line}; done
```
