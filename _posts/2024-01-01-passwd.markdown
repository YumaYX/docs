## 無期限設定

パスワードを無期限に設定する。

- `passwd -n 0`: 最短有効期間を0日(すぐ変更可能)に
- `passwd -x 99999`: 最長有効期間をほぼ無期限に
- `passwd -w -1`: 期限切れ警告をなしに

```sh
username='user'

passwd -n 0 ${username}
passwd -x 99999 ${username}
passwd -w -1 ${username}
chage -l ${username}
```

## パスワードの設定確認

```sh
chage -l ${username}
```

`chage -l` の `-l` は小文字のエル(L)である。

## 引数表 passwd / chage

| desc | passwd arg | chage arg | 設定なしvalue |
| --- | --- | --- | ---|
| MIN寿命 | -n | -m | 0 |
| MAX寿命 | -x | -M | 99999 |
| ワーニング(期限のn日前) | -w | -W | - |
