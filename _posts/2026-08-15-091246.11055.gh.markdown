## install

```sh
sudo dnf install 'dnf-command(config-manager)'
sudo dnf config-manager --add-repo https://cli.github.com/packages/rpm/gh-cli.repo
sudo dnf -y install gh
```

## auth

```sh
gh auth login
```

## repo list

```sh
gh repo list --json name --jq '.[].name'
```

```sh
gh repo list --json name --jq '.[].name' | while read line
do
    echo ${line}
    ys-gclone "${line}" > /dev/null 2>&1
    sleep 3
done
```

note: `ys-gclone` = `git clone git@github.com:YumaYX/`
