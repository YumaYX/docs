Ollamaインストールと簡単な使用例

- `serve`が動いていれば、APIを使用できる。
  - runした後、プロンプトを抜けても裏でserveが動いている。
  - モデルをpullしておけば、apiから呼び出せる。
- ハードと用途を考えてモデルを選ぶ。
- streamが初期設定となっている。`stream`を`false`にすると、使いやすいだろう。
- postで、bodyにjsonをつけて送る。

### テスト 

- host: `localhost`
- port: `11434`
- model: `gemma3`

#### チャット

`/api/chat`

```sh
curl http://localhost:11434/api/chat \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gemma3",
    "messages": [
      { "role": "user", "content": "write a simple sample code with ruby." }
    ],
    "stream": false
  }' | jq
```

##### 履歴付きチャット

`/api/chat`

```sh
curl http://localhost:11434/api/chat \
  -H "Content-Type: application/json" \
```

### Ruby での利用

```ruby
require 'net/http'
require 'uri'
require 'json'

# 送信先のURL
url = URI.parse('http://localhost:11434/api/chat')

# 送信するJSONデータ
data = {
    "model": "gemma3",
    "prompt": "write a simple sample code with ruby.",
    "stream": false
}

# HTTPリクエストを作成
http = Net::HTTP.new(url.host, url.port)
http.use_ssl = (url.scheme == "https")

request = Net::HTTP::Post.new(url.path, {
  'Content-Type' => 'application/json'
})

# JSONデータをボディに設定
request.body = data.to_json

# リクエスト送信 & レスポンス取得
response = http.request(request)

# レスポンス出力
puts "Status: #{response.code}"
puts "Body: #{response.body}"
```
