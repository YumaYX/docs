AlmaLinux 9.5 の ISO を USB メモリに書き込む手順。

書き込み先デバイスを誤ると他のディスクを破壊するため、`fdisk -l` で対象を十分確認してから `dd` を実行する。


```sh
url='https://ftp.riken.jp/Linux/almalinux/9.5/isos/x86_64/AlmaLinux-9.5-x86_64-dvd.iso'

curl -O $url
name=$(basename ${url})
sudo fdisk -l
```

```sh
device='/dev/sdb'

sudo dd if=./${name} of=${device} bs=1048576 status=progress
```

## 環境

```
AlmaLinux release 9.5 (Teal Serval)
```
