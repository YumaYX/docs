# Pythonで作成

```sh
python3 -c 'import crypt; print(crypt.crypt("mypassword", crypt.METHOD_SHA512))'
```

ハッシュ生成時にランダムなソルトが付与されるため、実行ごとに結果が異なる。

# opensslで作成

```sh
openssl passwd -6 -salt $(openssl rand -base64 6) password
```

- `-6`: SHA-512 を指定
- `-salt $(openssl rand -base64 6)`: ランダムなソルトを生成

> **Note:** Python 3.13 で `crypt` モジュールが削除されたため、新環境では `openssl passwd -6` を推奨。
